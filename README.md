# Nail - 窗口图钉工具

将任意 Windows 窗口"钉"在屏幕最前层，使其不被其他窗口遮挡。类似现实中的图钉，把窗口牢牢固定在画面最上层。

## 功能特性

- **图钉拖动附着**：拖动图钉到任意窗口（文档、图片、浏览器等）上即可附着
- **窗口置顶**：启用图钉后，被附着的窗口始终显示在最上层
- **图钉跟随窗口**：启用后图钉会跟随附着窗口一起移动，不会偏移
- **隐藏图钉**：可隐藏图钉图标（通过图钉菜单或主面板），窗口仍保持置顶
- **点击空白关闭菜单**：点击图钉弹出菜单后，点击其他区域自动关闭
- **多窗口置顶**：支持多个图钉同时工作，后启用的窗口置于更上层
- **系统托盘驻留**：关闭主窗口后最小化到托盘，图钉继续生效
- **彩色图钉**：红/橙/黄/绿/蓝/紫 六种颜色可选，方便区分不同窗口
- **活跃窗口一键置顶**：自动检测当前活跃窗口并置顶
- **安全退出**：退出程序时自动恢复所有被置顶窗口的普通状态

## 运行环境

- Windows 10 version 1809+ 或 Windows 11
- 64 位操作系统
- 无需安装 .NET 运行时（已自包含在 exe 中）

## 使用说明

### 启动程序

双击 `publish\Nail.exe` 即可运行。程序窗口标题为「Nail - 窗口图钉工具」。

### 方法一：新建图钉并拖动

1. 点击 **「📌 新建图钉」** 按钮，屏幕中央出现一个红色图钉
2. 按住图钉拖动到你想要置顶的窗口上（如 Word 文档、文本文档、图片查看器等）
3. 松开鼠标，图钉即附着到该窗口（变为橙色表示已附着但未启用）
4. 点击图钉，弹出菜单，选择 **「📌 启用置顶」**
5. 目标窗口立即置顶，图钉变为绿色，窗口将始终显示在最前层

### 方法二：一键置顶活跃窗口

1. 先点击你想要置顶的窗口，使其成为活跃窗口
2. 切回 Nail 主窗口，点击 **「🎯 置顶活跃窗口」**
3. 自动创建图钉并附着、启用

### 管理图钉

- **启用/禁用**：点击图钉 → 选择「启用置顶」或「取消置顶」
- **隐藏/显示**：点击图钉 → 选择「隐藏图钉」（图钉消失但置顶效果保留），或在主面板点击 👁/🔇 按钮
- **更换颜色**：点击图钉 → 选择「更换颜色」→ 选择喜欢的颜色
- **删除图钉**：点击图钉 → 选择「删除图钉」，或在主窗口列表中点击 × 按钮
- **主窗口管理**：在主窗口列表中可以看到所有图钉（包括隐藏的），直接点击按钮管理
- **关闭菜单**：点击图钉弹出菜单后，在图钉之外任意位置点击即可关闭菜单

### 托盤运行

- 关闭主窗口（点击右上角 ×）→ 程序最小化到系统托盘（右下角图标区域）
- 双击托盘图标 → 重新打开主窗口
- 右键托盘图标 → 可选择「显示主窗口」或「退出」
- 退出程序后，所有被置顶的窗口自动恢复普通状态

## 构建说明（开发者）

### 环境要求

- .NET 9.0 SDK（或更高版本）
- 下载地址：https://dotnet.microsoft.com/download

### 构建命令

```powershell
# 开发构建（依赖 .NET 运行时）
dotnet build -c Release

# 发布为独立单文件 exe（无需 .NET 运行时）
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
```

发布后的 `publish\Nail.exe` 可直接在 Windows 10/11 上运行，无需安装任何依赖。

### 修改目标框架

如需改为 .NET 8，修改 `Nail.csproj` 中的 `<TargetFramework>` 为 `net8.0-windows`。

## 常见问题

**Q: 图钉拖动后没有附着到窗口？**
A: 确保图钉尖端（底部）在目标窗口范围内再松开鼠标。桌面空白区域不会附着。

**Q: 置顶后窗口还是被某些窗口遮挡？**
A: 如果有多个图钉同时启用，后启用的窗口会在更上层。可以先将旧图钉禁用，再重新启用需要的图钉。

**Q: 关掉 Nail 后置顶效果消失了？**
A: 这是正常行为。退出程序时会自动恢复所有窗口。如需持久置顶，保持 Nail 在系统托盘运行即可。

**Q: 能否置顶文件资源管理器？**
A: 可以，几乎所有 Windows 窗口都支持置顶（包括资源管理器、记事本、Office、浏览器等）。
